# BPM-ESG-Metrics-SLR

Replication package and dataset associated with the systematic literature review
"Uma década de pesquisas sobre aderência de processos de negócio a requisitos ASG:
métricas, sustentabilidade e valor econômico".

The repository contains the final corpus of 110 studies, extraction and coding data,
search strategies, and supporting scripts used in the review.

## Repository contents

- `data/corpus_110_estudos.xlsx`: final corpus of 110 included studies.
- `data/matriz_extracao.xlsx`: extraction and coding matrix used for QP1, QP2 and QP3.
- `search-strategy/`: search strings and database-specific adaptations.
- `scripts/`: scripts used during screening and data processing.

## Search period

Searches were conducted in July and August 2026, covering publications from
2016 to 2026 in Portuguese and English.

Databases:
Scopus, ACM Digital Library, IEEE Xplore, SciELO, SBC OpenLib and SpringerLink.

## Replication package

This repository contains:

- `data/`: final corpus of 110 studies and extraction/coding data.
- `search-strategy/`: base search string and database-specific search strategies.
